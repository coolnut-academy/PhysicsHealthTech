# PhysicsHealthTech — Context Brief A: Teaching Documents & Worksheets

> ใช้เป็นไฟล์แนบ **เฉพาะแชทจัดทำเอกสาร/ใบงาน** ไม่ใช่เอกสารสเปกสำหรับพัฒนาเว็บไซต์
> Version: 1.0 | 1 พฤศจิกายน 2569

## 1. เป้าหมาย
ออกแบบชุดการจัดการเรียนรู้ Project-Based Learning (PBL) ฟิสิกส์บูรณาการสายสุขภาพสำหรับ **ม.4 และ ม.5 ระดับชั้นละ 20 คาบ** คาบละประมาณ 50 นาที (ให้ตรวจสอบเวลาเรียนจริงก่อนทำฉบับใช้งาน) ผู้เรียนต้องเรียนรู้หลักการฟิสิกส์และฝึกแก้โจทย์ในห้องก่อน จึงใช้ AI เป็นผู้ช่วยสร้างเว็บแอปด้านการศึกษาที่ประยุกต์ฟิสิกส์กับวิทยาศาสตร์สุขภาพ

**งานปลายทาง:** นักเรียนแต่ละคนทำ **โครงงานเดี่ยวอย่างน้อย 1 ชิ้น** (สามารถทำมากกว่า 1 ชิ้นได้ถ้ามีเวลา) และแต่ละกลุ่มทำ **โครงงานกลุ่มท้ายหน่วยเพียง 1 โครงงาน** พร้อมนำเสนอและสะท้อนการเรียนรู้

## 2. ขอบเขตสาระฟิสิกส์
- เลือกจากทั้งภาคเรียนที่ 1 และภาคเรียนที่ 2 ได้ ไม่จำกัดเทอมเดียว
- ม.4: การวัด/ความไม่แน่นอน การเคลื่อนที่แนวตรง แรงและกฎของนิวตัน สมดุลกล งานและพลังงาน โมเมนตัม การเคลื่อนที่แนวโค้ง ฯลฯ ตามหลักสูตรและแผนของโรงเรียน
- ม.5: SHM คลื่น แสง เสียง ไฟฟ้าสถิต และไฟฟ้ากระแส ฯลฯ ตามหลักสูตรและแผนของโรงเรียน
- ไม่พยายามยัดทุกบทเข้าหน่วย 20 คาบ: เป็นหน่วย PBL บูรณาการ เน้นแนวคิดฟิสิกส์ที่สัมพันธ์กับผลงานจริงอย่างชัดเจน
- ตัวอย่าง ม.4: Gait Speed Calculator, Wheelchair Force Simulator, Safe Surface Lab, โมเมนต์ของคาน/ไม้เท้า (ระบุข้อจำกัดแบบจำลอง)
- ตัวอย่าง ม.5: Ultrasound Echo Simulator, Vision Focus Simulator, Sound Intensity Lab, Optics/Endoscope Light Lab, วงจรอิเล็กทรอนิกส์อย่างง่าย
- ไม่สร้างข้ออ้างเรื่องการใช้ในคลินิกโดยไม่มีหลักฐาน และไม่ให้เว็บนักเรียนวินิจฉัยโรค/แนะนำการรักษา

## 3. ลำดับการจัดกิจกรรมที่ยึดร่วมกัน
1. **คาบ 1–6: Physics First** — ตั้งปัญหา เรียนทฤษฎี สาธิต/ทดลอง ฝึกแก้โจทย์ในห้อง ทดสอบความเข้าใจ
2. **คาบ 7–11: Individual Practice** — วาดและระบายสี UI บนกระดาษที่มี **กรอบจอมือถือและแท็บเล็ตเปล่า**; กรอกใบงาน Guide เพื่อออกแบบ Prompt; ถ่ายภาพงานวาด + พิมพ์ Prompt ส่งให้ AI สร้าง HTML/CSS/JS; ตรวจสมการและผลลัพธ์ด้วยคำตอบจากโจทย์ที่ทำด้วยมือ; ส่ง/นำเสนอโครงงานเดี่ยว
3. **คาบ 12–20: Group PBL** — เลือกปัญหาสุขภาพและหลักฟิสิกส์ที่ใช้จริง; แก้โจทย์และตรวจสมการ ทดลอง/หากรณีทดสอบ; วาด UI มือถือ/แท็บเล็ต; ออกแบบ Prompt กลุ่ม; สร้างและทดสอบแอป; เผยแพร่ผ่าน GitHub Pages; นำเสนอและสะท้อนผล
4. เช็กพอยต์ **Physics Verified → Design & Prompt Approved → Application Validated** ก่อนให้ผ่านแต่ละขั้น

## 4. สิ่งที่ต้องผลิตในแชทเอกสาร
- แผนการจัดการเรียนรู้/ภาพรวมหน่วย 20 คาบ **แยก ม.4 และ ม.5** พร้อมจุดประสงค์ ผลการเรียนรู้ สมรรถนะ กิจกรรม สื่อ หลักฐาน และวิธีประเมิน
- ชุดใบงานพร้อมพิมพ์: (ก) สำรวจปัญหา/อาชีพสุขภาพ (ข) แบบฝึกโจทย์ฟิสิกส์พร้อมช่องแสดงวิธีทำ (ค) ทดลองและบันทึกข้อมูล (ง) วาด UI มือถือ–แท็บเล็ตและระบายสี (จ) Prompt Design Guide (ฉ) ทดสอบสมการ/เว็บแอปด้วยมือ (ช) เสนอโครงงานกลุ่ม/บทบาท/บันทึกความก้าวหน้า (ซ) Reflection และ Showcase
- ใบงานสำคัญควรมี **ฉบับนักเรียน + แนวเฉลย/คู่มือครูแยก** ไม่ให้เฉลยหลุดปนในไฟล์นักเรียน
- Rubric ให้คะแนนที่เน้นความเข้าใจฟิสิกส์มากกว่าความสวยของเว็บ และมีคะแนนรายบุคคลควบคู่กับคะแนนกลุ่ม
- แบบตรวจ 3 จุด (checkpoints), แบบเก็บหลักฐาน และ checklist ก่อนนักเรียนถ่ายภาพใบงานส่งระบบ
- หากได้รับไฟล์เดิมจากผู้ใช้ ให้ตรวจโครงสร้างและใช้เป็นต้นฉบับก่อนออกแบบใหม่

## 5. มาตรฐานของใบงาน
- **ภาษาไทยเป็นหลัก** ใช้คำอังกฤษเฉพาะศัพท์เทคนิคพร้อมคำไทยกำกับ
- รูปแบบ **A4 พร้อมพิมพ์** เว้นพื้นที่เขียนคำตอบจริง ระยะขอบและกรอบช่องสม่ำเสมอ; เหมาะกับการถ่ายรูปส่งผ่านโทรศัพท์
- ช่องข้อมูลหัวใบงาน: ชื่อ–สกุล ชั้น/ห้อง เลขที่ รหัสนักเรียน ปีการศึกษา วันส่ง ชื่อใบงาน (จะปรับได้ตามรูปแบบโรงเรียน)
- **UI Drawing Sheet:** มีกรอบโทรศัพท์แนวตั้งและแท็บเล็ตแนวนอน **เปล่าให้วาดเอง** ไม่เติม UI สำเร็จรูป; เผื่อพื้นที่สำหรับระบายสีและคำอธิบายองค์ประกอบ
- **Prompt Guide:** ใช้คำถามเป็นขั้นตอน Problem / Audience / Physics & Units / Input–Output / UI from Drawing / Validation & Errors / Tech & GitHub Pages; มีช่องประกอบ Prompt ฉบับสุดท้าย
- **Physics Worksheet:** มีโจทย์หลายระดับ ช่องตั้งสมการ แทนค่า หน่วย วิเคราะห์ความสมเหตุสมผล และคำตอบที่ตรวจสอบได้
- **Test Worksheet:** มีค่าอินพุตอย่างน้อย 3 กรณี (ปกติ/ขอบเขต/ข้อมูลผิด) พร้อมช่องเปรียบเทียบคำตอบทำมือกับผลแอป
- สมการฟิสิกส์ต้องถูกต้องเชิงมิติ/หน่วย ตัวห้อย/ยกกำลัง/สัญลักษณ์ต้องไม่เพี้ยน; หากสร้าง .docx ให้ใช้สมการ Word ที่แก้ไขได้เมื่อทำได้
- ระบุข้อจำกัดของแบบจำลองทางการแพทย์ ไม่ให้แอปเพื่อการศึกษาอ้างว่าเป็นเครื่องมือวินิจฉัย

## 6. เกณฑ์คะแนนตั้งต้น (ปรับได้)
- ฟิสิกส์และโจทย์ในชั้นเรียน 30 คะแนน
- โปรเจกต์เดี่ยว (UI + Prompt + ความถูกต้อง + แอป) 20 คะแนน
- โครงงานกลุ่มด้านหลักฟิสิกส์และการทดสอบ 30 คะแนน
- การออกแบบและความร่วมมือ 10 คะแนน
- การนำเสนอและตอบคำถามรายบุคคล 10 คะแนน

## 7. กระบวนการส่งหลักฐาน
ครู **ตรวจใบงานกระดาษก่อน** แล้วนักเรียนถ่ายภาพส่งผ่าน PhysicsHealthTech ภายหลัง รายละเอียดระบบเว็บเป็นขอบเขตของอีกแชท; เอกสารแชทนี้มีหน้าที่เพียงเตรียมรูปแบบ/เลขที่ใบงาน/ชื่อกิจกรรม/เกณฑ์ประเมินให้สอดคล้องกัน ไม่เขียนโค้ดเว็บไซต์หรือออกแบบฐานข้อมูล

## 8. ข้อมูลตั้งต้นและสิ่งที่ยังไม่ได้ยืนยัน
- ปีการศึกษาในตัวอย่าง: 2569 ไม่ใช่ข้อจำกัดว่าใช้ได้เฉพาะปีนี้
- คาบละ 50 นาทีเป็นสมมติฐาน หากผู้ใช้มีตารางจริงให้ใช้ข้อมูลนั้น
- ม.4 และ ม.5 ใช้ชุดเอกสารโครงเดียวกันได้ แต่ **เนื้อหาโจทย์ เฉลย และตัวอย่างต้องต่างกันตามระดับชั้น**
- หากมีไฟล์หลักสูตร/แผนเดิม/ตราโรงเรียน/แม่แบบราชการ ให้ยึดไฟล์เหล่านั้นเมื่อผู้ใช้แนบมา
